# ChatRoad

AI 角色聊天 Web 应用 —— 一个基于 **React 18 + Vite + TypeScript** 的前端项目。

用于展示前端工程化与交互实现能力：组件化拆分、状态管理、路由、流式（SSE）渲染、Markdown 渲染与响应式布局。

## 技术栈

| 方向 | 选型 |
| --- | --- |
| 框架 / 构建 | React 18 · Vite 5 · TypeScript |
| 样式 | Tailwind CSS 3 |
| 路由 | React Router 6 |
| 状态管理 | Zustand |
| Markdown | react-markdown · remark-gfm |
| 流式对话 | Server-Sent Events（SSE） |

## 快速开始

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建
npm run lint     # ESLint 检查
npm run format   # Prettier 格式化
```
